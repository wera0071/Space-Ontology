# Space Ontology: пополнение таксономий методами NLP

Учебно-исследовательский проект МГУ по предсказанию гиперонимов
для терминов ракетно-космической техники.

## Подходы
- **2025:** FastText, семантические и структурные признаки,
  логистическая регрессия для предсказания гиперонимов.
- **2026:** сравнение LLM и промптов, сопоставление ответов
  с понятиями тезауруса, оценка по MAP@K и MRR@K.
